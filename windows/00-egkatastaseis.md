# Μέρος 1: Εγκαταστάσεις (Windows)

Σε αυτό το μέρος ετοιμάζεις τον υπολογιστή σου. Στο τέλος θα έχεις εγκατεστημένα τα Chrome, Antigravity, Python, Git και Ollama, ένα δωρεάν Gemini API key και τον φάκελο του workshop κατεβασμένο.

Αν κάποιο πρόγραμμα το έχεις ήδη, κάνε μόνο τον έλεγχο που περιγράφει το αντίστοιχο βήμα και προχώρα.

---

## 0. Τι χρειάζεσαι

- Windows 10 (64-bit, έκδοση 22H2 ή νεότερη) ή Windows 11. Για να δεις την έκδοση: πάτα `Win + R`, γράψε `winver` και πάτα Enter.
- Περίπου **6 GB ελεύθερο χώρο** στον δίσκο.
- Σύνδεση στο internet. Το πιο μεγάλο κατέβασμα είναι το μοντέλο Gemma, περίπου 0,8 GB.
- Έναν **προσωπικό λογαριασμό Gmail**. Όχι τον λογαριασμό του πανεπιστημίου, γιατί σε αυτούς τους λογαριασμούς συχνά δεν επιτρέπονται τα εργαλεία AI της Google.

## 1. Το terminal

Το terminal είναι ένα παράθυρο όπου γράφεις εντολές αντί να πατάς κουμπιά. Στο workshop το χρησιμοποιείς για λίγα πράγματα: για να ελέγξεις ότι κάτι εγκαταστάθηκε, να κατεβάσεις το repo και να τρέξεις τα tests.

### Πώς το ανοίγεις

Στα Windows χρησιμοποιείς το **PowerShell**.

1. Πάτα το πλήκτρο **Windows** ή κάνε κλικ στο Start.
2. Γράψε `PowerShell`.
3. Κάνε κλικ στο **Windows PowerShell**. **Όχι** «Run as administrator»: κανένα βήμα του workshop δεν χρειάζεται δικαιώματα διαχειριστή.


Στα Windows 11 μπορεί να ανοίξει η εφαρμογή **Terminal** με το PowerShell μέσα. Είναι το ίδιο πράγμα.

### Τι βλέπεις και πώς γράφεις

Το παράθυρο δείχνει μια γραμμή που τελειώνει σε `>`. Αυτό λέγεται **prompt** και σημαίνει ότι το terminal περιμένει εντολή. Ό,τι γράφεται πριν από αυτό το σύμβολο είναι ο φάκελος όπου βρίσκεσαι τώρα.

- **Επικόλληση εντολής:** Ctrl+V (ή δεξί κλικ μέσα στο παράθυρο).
- **Εκτέλεση:** πατάς Enter.
- **Διακοπή εντολής που τρέχει:** `Ctrl + C`.
- **Νέο terminal:** κλείνεις το παράθυρο και ανοίγεις ξανά όπως παραπάνω. Μετά από κάθε εγκατάσταση προγράμματος ανοίγεις **νέο** terminal, γιατί τα παλιά παράθυρα δεν «βλέπουν» τα καινούργια προγράμματα.

### Δοκίμασέ το

Εντολή στο terminal:

```
(Get-Location).Path
```

**Τι πρέπει να δεις:** μια διαδρομή όπως `C:\Users\maria`, με το δικό σου όνομα χρήστη. Αυτός είναι ο προσωπικός σου φάκελος.

## 2. Chrome

Ο agent του Antigravity ανοίγει τον Chrome για να δοκιμάζει την εφαρμογή σου. Γι' αυτό τον θέλουμε εγκατεστημένο και **προεπιλεγμένο browser**.

### Εγκατάσταση

1. Άνοιξε το **google.com/chrome** από τον browser που έχεις.
2. Πάτα **Download Chrome** και άνοιξε το αρχείο που κατέβηκε.
3. Περίμενε να τελειώσει η εγκατάσταση. Ο Chrome ανοίγει μόνος του.

### Ορισμός ως προεπιλεγμένος browser

1. Πάτα το Start και άνοιξε **Settings** (το γρανάζι).
2. Πήγαινε **Apps** → **Default apps**.
3. Βρες και πάτα **Google Chrome**.
4. Πάτα **Set default** στο πάνω μέρος.


**Τι πρέπει να δεις:** αν κάνεις κλικ σε ένα link από άλλη εφαρμογή, ανοίγει ο Chrome.

## 3. Antigravity

Το Antigravity είναι η εφαρμογή της Google όπου δουλεύεις μαζί με τον AI agent.

### Κατέβασμα

1. Στον Chrome, άνοιξε το **antigravity.google/download**.
2. Διάλεξε την έκδοση για **Windows**. Οι περισσότεροι υπολογιστές θέλουν την **x64**. Την **ARM64** τη θέλεις μόνο αν έχεις laptop με επεξεργαστή Snapdragon. Αν δεν ξέρεις: Settings → System → About → **System type**.


### Εγκατάσταση

1. Άνοιξε το αρχείο `.exe` που κατέβηκε (θα το βρεις στα Downloads).
2. Αν εμφανιστεί το μπλε παράθυρο **Windows protected your PC**, πάτα **More info** → **Run anyway**.
3. Στον οδηγό εγκατάστασης πάτα **Next** σε κάθε οθόνη, κρατώντας τις προεπιλογές, και στο τέλος **Install** και **Finish**.


### Πρώτη εκκίνηση και σύνδεση

1. Ακολούθησε τις οθόνες καλωσορίσματος. Όπου σε ρωτάει για θέμα, εμφάνιση ή ρυθμίσεις, κράτα τις προεπιλογές.
2. Όταν ζητήσει σύνδεση, πάτα **Sign in with Google**. Ανοίγει ο Chrome.
3. Διάλεξε το **προσωπικό** σου Gmail και πάτα **Allow** / **Continue** όπου ζητηθεί.
4. Όταν ο browser γράψει ότι η σύνδεση ολοκληρώθηκε, γύρνα στο Antigravity.


**Τι πρέπει να δεις:** το κεντρικό παράθυρο του Antigravity, με πεδίο για να γράψεις μήνυμα στον agent.

## 4. Python

Το Study Copilot γράφεται σε Python. Χρειάζεσαι έκδοση **3.10 ή νεότερη**.

### Έλεγχος αν την έχεις ήδη

Εντολή στο terminal:

```
py --version
```

Αν δεις `Python 3.10` ή μεγαλύτερο αριθμό (π.χ. `Python 3.12.7`), την έχεις ήδη. Προχώρα στο βήμα 5.

Αν δεις μήνυμα ότι το `py` δεν αναγνωρίζεται (`is not recognized`), συνέχισε με την εγκατάσταση.

### Εγκατάσταση

1. Άνοιξε το **python.org/downloads/windows**.
2. Κάτω από **Stable Releases**, βρες την πιο πρόσφατη **Python 3.13** και πάτα **Download Windows installer (64-bit)**.
3. Άνοιξε το αρχείο που κατέβηκε.
4. **Πριν πατήσεις οτιδήποτε άλλο**, τσέκαρε στο κάτω μέρος του παραθύρου το κουτάκι **Add python.exe to PATH**.
5. Πάτα **Install Now**.
6. Αν στο τέλος εμφανιστεί **Disable path length limit**, πάτα το.
7. Πάτα **Close**.


8. Κλείσε το PowerShell, άνοιξε **νέο** και τρέξε ξανά:
   ```
   py --version
   ```

Στα Windows χρησιμοποιείς πάντα `py` και όχι `python`. Αν γράψεις `python`, τα Windows μπορεί να ανοίξουν το Microsoft Store αντί για την Python.

**Τι πρέπει να δεις:** `Python 3.10` ή νεότερη.

## 5. Git

Το Git κατεβάζει το repo του workshop και κρατάει το ιστορικό των αλλαγών σου.

### Έλεγχος

Εντολή στο terminal:

```
git --version
```

Αν δεις κάτι σαν `git version 2.4x.x`, το έχεις. Προχώρα στο βήμα 6.

### Εγκατάσταση

1. Άνοιξε το **git-scm.com/downloads/win**.
2. Πάτα **Click here to download** (κατεβαίνει η 64-bit έκδοση).
3. Άνοιξε το αρχείο. Αν ρωτήσει αν επιτρέπεις αλλαγές στη συσκευή, πάτα **Yes**.
4. Πάτα **Next** σε κάθε οθόνη. Μία μόνο αλλαγή: στην οθόνη **Choosing the default editor used by Git**, διάλεξε από τη λίστα **Use Notepad as Git's default editor**. Η προεπιλογή (Vim) είναι δύσκολη για αρχάριους.
5. Στο τέλος πάτα **Install** και μετά **Finish**.


6. Κλείσε το PowerShell, άνοιξε νέο και έλεγξε ξανά με `git --version`.

### Πες στο Git ποιος είσαι

Κάθε αλλαγή που αποθηκεύεις (commit) γράφει όνομα και email. Εντολές στο terminal, βάζοντας τα δικά σου στοιχεία μέσα στα εισαγωγικά:

```
git config --global user.name "Το Όνομά Σου"
git config --global user.email "to-email-sou@gmail.com"
```

Αν σκοπεύεις να ανεβάσεις το project στο GitHub (Μέρος 6), βάλε το ίδιο email με τον λογαριασμό σου στο GitHub.

## 6. Ollama και το μοντέλο Gemma

Το Ollama τρέχει μοντέλα AI μέσα στον υπολογιστή σου, χωρίς internet. Το χρειάζεσαι στο Μέρος 5, αλλά το κατέβασμα του μοντέλου παίρνει χρόνο, οπότε το ξεκινάς τώρα.

### Εγκατάσταση

1. Άνοιξε το **ollama.com/download** και διάλεξε **Windows**.
2. Πάτα **Download for Windows**. Κατεβαίνει το `OllamaSetup.exe`.
3. Άνοιξέ το και πάτα **Install**. Δεν χρειάζεται δικαιώματα διαχειριστή.
4. Όταν τελειώσει, το Ollama τρέχει στο παρασκήνιο. Θα δεις το εικονίδιό του (ένα λαμά) κάτω δεξιά στη γραμμή εργασιών, ίσως μέσα στο βελάκι `^`.


### Κατέβασμα του Gemma

Άνοιξε **νέο** terminal. Εντολή:

```
ollama pull gemma3:1b
```

Θα δεις μια μπάρα προόδου. Είναι περίπου 0,8 GB. **Άφησε αυτό το παράθυρο ανοιχτό** και συνέχισε με τα επόμενα βήματα σε άλλο terminal. Αν διακοπεί, τρέξε ξανά την ίδια εντολή: συνεχίζει από εκεί που σταμάτησε.


**Τι πρέπει να δεις στο τέλος:** τη λέξη `success`. Για επιβεβαίωση:

```
ollama list
```

Πρέπει να εμφανίζεται μια γραμμή με `gemma3:1b`.

## 7. Το Gemini API key

Το API key είναι ένας κωδικός που επιτρέπει στην εφαρμογή σου να χρησιμοποιεί το Gemini. Είναι δωρεάν και δεν χρειάζεται κάρτα.

1. Άνοιξε το **aistudio.google.com** και συνδέσου με το **ίδιο προσωπικό Gmail** που έβαλες στο Antigravity.
2. Αν σε ρωτήσει για όρους χρήσης, αποδέξου τους.
3. Πάτα **Get API key** (στο μενού αριστερά ή κάτω αριστερά).
4. Πάτα **Create API key**. Αν σε ρωτήσει για project, διάλεξε το προεπιλεγμένο ή πάτα **Create API key in new project**.
5. Εμφανίζεται ένα μεγάλο κλειδί που ξεκινά συνήθως με `AIza`. Πάτα το κουμπί αντιγραφής.


6. Επικόλλησέ το σε ένα σημείωμα στον υπολογιστή σου, μόνο για λίγο. Στο Μέρος 2 θα το μεταφέρεις σε ασφαλές αρχείο και μετά μπορείς να σβήσεις το σημείωμα.

**Μην στείλεις ποτέ το κλειδί σε κανέναν, μην το επικολλήσεις σε chat (ούτε στον agent) και μην το βγάλεις σε screenshot.** Αν το κλειδί διαρρεύσει, μπορεί να το χρησιμοποιήσει οποιοσδήποτε με τον δικό σου λογαριασμό. Σε αυτή την περίπτωση το σβήνεις από την ίδια σελίδα και φτιάχνεις νέο.

## 8. Κατέβασε το repo του workshop

Θα βάλεις το workshop σε έναν φάκελο `agy-101` μέσα στον προσωπικό σου φάκελο. Εντολές στο terminal, μία μία:

```powershell
mkdir $HOME\agy-101
cd $HOME\agy-101
git clone https://github.com/sma234/study-copilot.git
cd study-copilot
dir
```

**Τι πρέπει να δεις:** η τελευταία εντολή δείχνει μεταξύ άλλων τα `README.md`, `sample_lectures`, `workshop`, `windows`, `macos` και `linux`.


Κάνε clone **μόνο μία φορά**. Από εδώ και πέρα δουλεύεις πάντα σε αυτόν τον φάκελο:

```
C:\Users\maria\agy-101\study-copilot
```

(με το δικό σου όνομα χρήστη στη θέση του `maria`).

Αν το `git clone` αποτύχει, μπορείς να κατεβάσεις το repo ως ZIP: στη σελίδα github.com/sma234/study-copilot πάτα το πράσινο **Code** → **Download ZIP**, αποσυμπίεσέ το μέσα στο `agy-101` και μετονόμασε τον φάκελο σε `study-copilot`. Το ZIP δεν έχει ιστορικό Git, οπότε στο Μέρος 6 θα χρειαστείς `git init`. Προτίμησε το clone αν γίνεται.
